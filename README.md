# 旧国名あて

武蔵・薩摩・讃岐のような昔の国の名前（旧国名・令制国）について、今の都道府県・五畿七道・読みを当てる1日5問のゲームです。68か国が、遊ぶうちに身につきます。「むずかしい」は国の読みをひらがなで入れて答えます。知らなくても、まちがえながら覚えられます。

- 遊ぶ：<https://satou-aaaaa.github.io/kyukoku-mei/>
- 今日の5問はだれでも同じで1日1回。とことん・練習は何度でも遊べます。時間制限はありません。
- 記録は遊ぶ人のブラウザの中だけに残り、外へは送りません。

## 国の名前・読みの出典

- 68か国（66か国と壱岐・対馬）と五畿七道の分け方：Wikipedia「令制国一覧」「五畿七道」「山陰道」、英語版 Wikipedia「Nankaidō」で確かめました。
- 読み：Wikipedia「令制国一覧」と、英語版 Wikipedia「Provinces of Japan」のローマ字で照らし合わせました。
- 今の都道府県：国の「おもな所」です。国と県のさかいはぴったりとは重ならないので、2つ以上の県にかかる国は説明にほかの県も出し、答えの選び肢には入れません。
- 学ぶ範囲：文部科学省 中学校学習指導要領（平成29年告示）社会。
